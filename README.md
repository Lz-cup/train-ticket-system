# 火车票务系统
一个基于 Spring Boot 的火车票购票后端系统，实现车次查询、在线购票、权限管理、订单超时自动关闭等功能。
## 技术栈
- 后端：Java、Spring Boot、MyBatis-Plus
- 数据库：MySQL
- 缓存：Redis
- 构建工具：Maven
## 功能模块
- **用户权限管理**：基于 RBAC 模型，实现 5 类用户角色、20+ 权限点的细粒度访问控制
- **车次查询**：支持按出发站、到达站、日期查询车次余票
- **在线购票**：选座下单、订单创建
- **并发控制**：使用 Redis 控制购票并发，防止车票超卖
- **订单超时处理**：定时任务自动关闭超时未支付订单，释放车票库存
- **客流统计**：按车次/时间段统计客流数据
## 核心实现
1. **RBAC 权限模型**：用户—角色—权限三层映射，通过拦截器在请求进入 Controller 前校验权限
2. **Redis 防超卖**：购票请求先在 Redis 中扣减余票，扣减成功才创建订单，避免并发下超卖
3. **定时关单**：使用 Spring `@Scheduled` 定时扫描超时未支付订单，自动关闭并回补库存

## 启动方式
1. 创建 MySQL 数据库，执行建表语句
2. 修改 `application.yml` 中的数据库连接和 Redis 地址
3. 运行 `TrainTicketApplication.java` 启动项目
4. 默认端口：8080
